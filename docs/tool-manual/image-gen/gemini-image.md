## 这个工具做什么

Gemini Image 适合快速生成简单、克制的科研插图或概念草图，用来先把视觉方向跑通。
## 适合什么问题

当你要先验证构图和风格方向，再决定是否进入精修时，用 Gemini Image。
## 指导架构

1. 第一层是先明确画面用途，是论文示意图、汇报图还是封面草图。
2. 第二层是把画面拆成主体、背景、标注和颜色四个部分。
3. 第三层是先追求结构正确，再追求细节精致。
4. 第四层是把草图反馈给后续更强控制的工具继续迭代。
## 推荐使用流程

1. 先说明图像用途和最终展示场景。
2. 限制风格、配色和构图，避免生成过于复杂的画面。
3. 先拿到概念草图，再根据效果调整。
4. 如果结果接近需求，再进入更细的视觉工具。

```text
生成一张扁平风格的免疫细胞示意图，白底、蓝色系、适合论文方法图。
```

### 流程草图

```text
生成一个简洁的生物研究流程图，突出样本收集、分析和结论三个阶段。
```
## 常见误区

- 一开始就追求细节和复杂构图。
- 不给用途，只说“生成一张好看的图”。
- 没有限制颜色和风格，导致结果不稳定。
## 和相邻工具的区别

- 和 ChatGPT 图像生成搭配时，Gemini Image 更适合快速草图。
- 和 Flowith 或 Lovart 搭配时，Gemini Image 可以先做方向预演。

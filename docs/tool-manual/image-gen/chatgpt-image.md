# ChatGPT (GPT Image 2) 使用说明

> 分类：学术绘图  |  按钮入口：立即生成  |  适用日期：2026-05-06
> 目标：把这个工具页写成可直接交给网页改版 AI 的完整说明稿。

## 这个工具做什么

ChatGPT 图像生成适合执行更明确的提示词，尤其适合先写提示词、再按需求做风格收敛。
## 适合什么问题

当你已经有很明确的画面描述，想让图像尽量贴合提示词时，用 ChatGPT 图像生成。
## 指导架构

1. 第一层是先把用途和受众写清楚，图像是论文插图、PPT 还是封面。
2. 第二层是给出构图、风格、配色和禁忌元素，让生成更可控。
3. 第三层是用多轮提示词微调不满意的部分。
4. 第四层是把最终可用版本整理成可复用的提示模板。
## 推荐使用流程

1. 先明确图像用途和风格目标。
2. 给出主体、背景、颜色、布局和负面约束。
3. 根据输出逐轮微调提示词。
4. 把效果最好的提示词保存成模板。
## 中文使用示例

### 论文插图

```text
请生成一张医学论文风格插图：巨噬细胞吞噬病原体，扁平设计，白色背景，蓝绿色为主，适合方法图。
```

### 封面图草案

```text
请生成一个科研报告封面图，主题是肿瘤免疫微环境，风格克制、专业、带一点未来感。
```
## 常见误区

- 提示词太泛，只要求“好看”。
- 不写负面约束，导致风格跑偏。
- 生成后没有把有效提示词沉淀下来。
## 和相邻工具的区别

- 和 Gemini Image 搭配时，ChatGPT 图像更适合精确提示。
- 和 Flowith 搭配时，ChatGPT 可以先负责提示词整理，再进入多节点生成。
## 给网页改造 AI 的提示

- 网页里要把“提示词执行”写成核心卖点。
- 示例最好直接表现“主体 + 风格 + 约束”的提示结构。

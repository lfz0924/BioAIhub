## 这个工具做什么

Flowith 更适合节点式生成工作流，适合把草图、提示词、变体和最终版本拆开管理。
## 适合什么问题

当你想同时试多个视觉方向，并且希望在多轮里比较效果时，用 Flowith。
## 指导架构

1. 第一层是先建立主题节点，明确你到底在做哪一类视觉表达。
2. 第二层是扩展风格、元素和变体节点，把探索过程显式化。
3. 第三层是把效果最好的分支继续细化，淘汰噪声分支。
4. 第四层是把最终流程沉淀为你的固定生成套路。
## 推荐使用流程

1. 先建立一个主题节点，说明图像目标。
2. 再分裂出多个风格或构图分支。
3. 比较不同分支的视觉表现。
4. 保留最好的方案继续细化。
## 中文使用示例

### 多方向探索

```text
请为“肿瘤免疫机制图”生成 3 个方向：极简医学风、编辑部信息图风、稍具科技感的科研风。
```

### 节点式迭代

```text
先输出构图，再输出配色，再输出最终渲染提示词。
```
## 常见误区

- 一开始就追求终稿，不做分支比较。
- 没有记录每个分支的优缺点。
- 节点太多，反而让探索失控。
## 和相邻工具的区别

- 和 Gemini Image 搭配时，Gemini 可以先做快速草图，Flowith 再做分支探索。
- 和 Lovart 搭配时，Flowith 更适合探索阶段，Lovart 更适合成品阶段。
## 给网页改造 AI 的提示

- 网页说明要把“节点”和“分支”讲清楚。
- 示例应体现多方向探索，而不是单次生成。

## 这个工具做什么

Lovart 适合做更偏成品导向的视觉输出，尤其适合把科研内容整理成完整、可交付的插图或展示素材。
## 适合什么问题

当你已经有明确主题，希望图像更接近最终交付物时，用 Lovart。
## 指导架构

1. 第一层是先明确最终用途，是论文插图、汇报图还是海报素材。
2. 第二层是把信息控制在一个主题里，避免画面过满。
3. 第三层是输出后只做局部微调，尽量保持整体完整性。
4. 第四层是把成品风格沉淀成可复用模板。
## 推荐使用流程

1. 先定义图像最终用途。
2. 把内容压缩成一个主主题。
3. 输出后只微调局部细节。
4. 把成功版本保存为后续模板。
## 中文使用示例

### 成品风插图

```text
生成一张适合学术汇报封面的科研插图，主题是“肿瘤免疫治疗路径”，整体干净、克制、专业。
```

### 展示素材

```text
生成一张适合 PPT 的医学信息图，展示研究流程和结果要点。
```
## 常见误区

- 信息塞太多，导致画面重点不清。
- 先追求系列化，忽略单张质量。
- 没有先定义用途，结果风格不稳定。
## 和相邻工具的区别

- 和 Flowith 搭配时，Flowith 负责探索，Lovart 负责成品。
- 和 ChatGPT 图像生成搭配时，ChatGPT 更适合精确提示，Lovart 更适合完成度。

# Scite.ai 使用说明

> 分类：学术写作  |  按钮入口：引用审计  |  适用日期：2026-05-06
> 目标：把这个工具页写成可直接交给网页改版 AI 的完整说明稿。

## 这个工具做什么

Scite.ai 适合做引用方向审查，重点是看一篇论文在后续文献中到底是被支持、被反驳，还是仅仅被提及。
## 适合什么问题

当你要检查引用可靠性，或者想知道某篇论文的真实学术影响时，用 Scite。
## 指导架构

1. 第一层是先确认目标论文和 DOI，避免引用对象混淆。
2. 第二层是查看支持、冲突和提及的分布，判断证据方向。
3. 第三层是重点关注争议较大的论文，因为这些论文最需要回原文核对。
4. 第四层是把审计结果用于选引用、写讨论部分或筛选参考文献。
## 推荐使用流程

1. 输入目标论文或 DOI。
2. 查看支持、冲突和提及的整体分布。
3. 识别分歧最明显的文献，再回原文核对方法和样本。
4. 根据审计结果决定引用优先级。
## 中文使用示例

### 引用方向检查

```text
请帮我检查这篇论文后续是被支持更多，还是被质疑更多，并告诉我为什么。
```

### 参考文献筛选

```text
请帮我判断这 3 篇候选参考文献里，哪一篇更适合作为结论部分的核心引用。
```
## 常见误区

- 把被引用次数等同于可靠性。
- 不看冲突论文，只看支持论文。
- 引用审计做完后，不回原文确认关键结论。
## 和相邻工具的区别

- 和 Paperpal 搭配时，先润色语言，再审查引用。
- 和 PubMed 搭配时，PubMed 负责找文献，Scite 负责检查文献地位。
## 给网页改造 AI 的提示

- 网页文案要把“支持/反驳/提及”写清楚。
- 示例最好体现“选引用”和“审计引用”两类任务。

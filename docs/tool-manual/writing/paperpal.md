# Paperpal 使用说明

> 分类：学术写作  |  按钮入口：精修润色  |  适用日期：2026-05-06
> 目标：把这个工具页写成可直接交给网页改版 AI 的完整说明稿。

## 这个工具做什么

Paperpal 适合英文论文的语言层面打磨，重点是句式、术语、语法和正式表达的一致性。
## 适合什么问题

当你已经有草稿，想提升英文表达质量时，用 Paperpal。
## 指导架构

1. 第一层是先保留你的原始研究意图，不要让润色工具改掉事实。
2. 第二层是让工具只做语言级改写，不去重新设计研究结论。
3. 第三层是逐句核对术语、缩写和数据，确保没有语义漂移。
4. 第四层是把润色后的句子统一到全文风格里，避免段落之间风格不一致。
## 推荐使用流程

1. 先写出你的原始句子或段落。
2. 让工具对语法、时态和语气做修正。
3. 检查专业术语和缩写有没有被错误替换。
4. 把通过检查的句子合并回全文。
## 中文使用示例

### 句子润色

```text
请把这句话改成更符合医学论文风格的英文：IL-17 在肿瘤微环境中可能影响 CD8+ T 细胞耗竭。
```

### 段落改写

```text
请把下面这一段改得更正式、更适合结果部分，但不要改变原意。
```
## 常见误区

- 让润色工具改动研究事实或结论。
- 不检查专业名词，直接采用改写结果。
- 把整篇文章一次性重写，失去原本的论证结构。
## 和相邻工具的区别

- 和 Ludwig 搭配时，Paperpal 负责整体润色，Ludwig 负责短语是否地道。
- 和 Scite 搭配时，先润色文本，再审查引用是否可靠。
## 给网页改造 AI 的提示

- 网页里要明确它是“语言优化”，不是“内容重写”。
- 示例最好体现“保留原意”的约束。

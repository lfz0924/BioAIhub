# ima.qq.com 使用说明

> 分类：深度分析  |  按钮入口：访问数据库  |  适用日期：2026-05-06
> 目标：把这个工具页写成可直接交给网页改版 AI 的完整说明稿。

## 这个工具做什么

ima.qq.com 更像个人知识库和多文档检索仓库，适合长期沉淀论文、笔记和跨文档问答。
## 适合什么问题

当你想把资料放进一个可复用的知识库，并持续用中文检索时，用 ima.qq.com。
## 指导架构

1. 第一层是建立稳定的个人知识库，而不是临时上传单篇文档。
2. 第二层是按主题、项目或研究方向持续积累材料。
3. 第三层是用跨文档问答找共识和差异，而不是只问某一篇文献。
4. 第四层是把结果整理成长期可复用的研究笔记。
## 推荐使用流程

1. 先按研究主题搭建你的知识库结构。
2. 持续上传论文、资料和自己的笔记。
3. 用跨文档问题检索关键信息和共识。
4. 把高价值答案整理成可复用的中文总结。
## 中文使用示例

### 知识库问答

```text
请基于我上传的所有论文，回答“IL-17 在肿瘤中的作用到底偏促进还是抑制？”并说明不同文档里的证据差异。
```

### 跨文档提纲

```text
请把这批文献按研究对象、实验系统、结论方向和局限性整理成中文提纲。
```
## 常见误区

- 知识库命名混乱，后续检索很难复用。
- 把它当一次性聊天工具，而不是长期积累空间。
- 没有把跨文档问题拆细，导致答案过于泛化。
## 和相邻工具的区别

- 和 Elicit 搭配时，ima 更适合长期沉淀，Elicit 更适合结构化抽取。
- 和 Kimi 搭配时，ima 负责知识库，Kimi 负责批量总结。
## 给网页改造 AI 的提示

- 网页介绍应强调“个人知识库”而不是普通问答。
- 文档里最好突出“长期积累”和“跨文档检索”。

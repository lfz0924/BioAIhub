# Elicit 使用说明

> 分类：深度分析  |  按钮入口：提取数据  |  适用日期：2026-05-06
> 目标：把这个工具页写成可直接交给网页改版 AI 的完整说明稿。

## 这个工具做什么

Elicit 适合把文献整理成结构化对比表，特别是样本量、方法、主要发现、结论和局限这些字段。
## 适合什么问题

当你要做文献矩阵、系统综述表或比较分析时，用 Elicit。
## 指导架构

1. 第一层是先明确你要抽取哪些字段，字段设计越清楚，结果越稳定。
2. 第二层是先筛文献，再抽字段，避免把噪声材料一起带进表格。
3. 第三层是把抽取结果和原文逐项核对，尤其注意样本量、分组和结论表述。
4. 第四层是把表格结果转成综述段落或比较图，而不是停留在表格本身。
## 推荐使用流程

1. 先确定你要比较的维度，比如样本量、干预方式、主要结果和局限。
2. 围绕主题检索并筛选相关论文。
3. 新增字段后检查每一列是否稳定抽取。
4. 把结果整理成中文表格，并对无法自动判断的内容做人工修订。
## 中文使用示例

### 综述表格抽取

```text
请帮我整理肿瘤免疫治疗研究中的样本量、干预方式、主要结果和局限性四列，输出成适合中文综述使用的对比表。
```

### 机制比较

```text
请对比不同论文中 IL-17 的上调和下调作用，并把结果整理成“研究对象、实验系统、核心结论、争议点”四列。
```
## 常见误区

- 字段定义太模糊，导致抽取结果不可比。
- 只看自动抽取，不回原文确认边界条件。
- 抽完表格就结束，没有把表格转换成综述语言。
## 和相邻工具的区别

- 和 Wispaper 搭配时，Wispaper 负责读单篇，Elicit 负责抽多篇。
- 和 Kimi 搭配时，Elicit 负责结构化数据，Kimi 负责批量总结。
## 给网页改造 AI 的提示

- 网页上最好把“抽取字段”写成独立区域。
- 文档要提醒用户：抽取结果是初稿，不是终稿。

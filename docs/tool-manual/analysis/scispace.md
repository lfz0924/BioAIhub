# SciSpace 使用说明

> 分类：深度分析  |  按钮入口：深度阅读  |  适用日期：2026-05-06
> 目标：把这个工具页写成可直接交给网页改版 AI 的完整说明稿。

## 这个工具做什么

SciSpace 适合直接对 PDF 做交互式阅读，尤其是解释公式、图表和复杂方法学段落。
## 适合什么问题

当你要边看 PDF 边提问，或者需要解释图表和公式时，用 SciSpace。
## 指导架构

1. 第一层是把 PDF 当成可对话对象，而不是只把它当成静态文件。
2. 第二层是围绕图、表、公式和方法学段落逐个提问，逐步吃透论文。
3. 第三层是把解释结果反写成你的阅读笔记，避免只停留在问答记录。
4. 第四层是当单篇读懂之后，再决定是否需要 Elicit 做多篇抽取。
## 推荐使用流程

1. 上传目标论文 PDF。
2. 先从标题、摘要和图表开始提问，再深入到方法和统计。
3. 把不理解的公式或图表单独圈出来问。
4. 将回答整理成你的中文读书笔记。
## 中文使用示例

### 公式解释

```text
请解释这段公式在做什么，并用中文说明每个变量的意义、作者为什么要这么设计。
```

### 图表解读

```text
请帮我读懂这张图，重点说明横轴、纵轴、颜色代表什么，以及作者想证明什么。
```
## 常见误区

- 没有先看论文结构，就直接问非常细的技术问题。
- 把工具解释直接抄进笔记，不自己复述一遍。
- 批量任务还逐篇深读，效率太低。
## 和相邻工具的区别

- 和 Elicit 搭配时，SciSpace 负责深读单篇，Elicit 负责抽多篇数据。
- 和 Wispaper 搭配时，两者都能读文献，但 SciSpace 更强调 PDF 交互。
## 给网页改造 AI 的提示

- 网页文案里要强调“边读边问”。
- 示例最好覆盖公式、图表和方法学三种常见场景。

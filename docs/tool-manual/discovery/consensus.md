# Consensus 使用说明

> 分类：文献发现  |  按钮入口：验证假设  |  适用日期：2026-05-06
> 目标：把这个工具页写成可直接交给网页改版 AI 的完整说明稿。

## 这个工具做什么

Consensus 适合回答明确的科学判断题，重点是快速看文献方向是否一致，而不是替代完整综述。
## 适合什么问题

当你已经有一个可判断的问题，想先看证据方向，再决定是否深入检索时，用 Consensus。
## 指导架构

1. 第一层是把问题写成单句判断题，最好是 Yes/No、支持/反对、促进/抑制这种可对立表达。
2. 第二层是先看整体证据倾向，再看分歧点和证据密度，避免只盯结论摘要。
3. 第三层是把判断结果转回原始文献核对，因为摘要层面的结论可能过于简化。
4. 第四层是如果证据不够一致，回到 PubMed 或 ResearchRabbit 继续扩展，而不是停在一个平台。
## 推荐使用流程

1. 先用一句话明确你的判断问题，尽量不要把多个问题塞进同一句。
2. 把问题写成工具容易理解的表达，例如“是否”“能否”“会不会”。
3. 观察结果里支持、反对和不确定的比例，再找分歧最大的点。
4. 把关键争议点带回原文或上游检索工具继续验证。
## 中文使用示例

### 判断疗效方向

```text
请帮我判断：补充肌酸是否能改善认知功能？请告诉我目前文献倾向、证据是否一致，以及我下一步应该回到哪里查原文。
```

### 判断机制关系

```text
请判断：IL-17 是否会促进肿瘤微环境中的免疫抑制？如果证据不一致，请列出可能的分歧来源。
```
## 常见误区

- 把问题写得太宽，导致结果只是泛泛共识。
- 把“有文献提到”误解成“有高质量证据支持”。
- 不看证据分歧，直接把结论写进文稿。
## 和相邻工具的区别

- 和 PubMed 搭配时，Consensus 负责方向判断，PubMed 负责找到原始研究。
- 和 Wispaper 搭配时，先由 Consensus 定方向，再由 Wispaper 深读关键论文。
## 给网页改造 AI 的提示

- 网页文案最好保留“验证假设”这类判断式按钮语义。
- 结果区建议强调“支持/反对/不确定”的对立结构。

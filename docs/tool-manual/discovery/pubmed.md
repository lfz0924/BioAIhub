# PubMed 使用说明

> 分类：文献发现  |  按钮入口：访问数据库  |  适用日期：2026-05-06
> 目标：把这个工具页写成可直接交给网页改版 AI 的完整说明稿。

## 这个工具做什么

PubMed 是生物医学检索的起点，适合用标准化术语把问题拆开，再用英文检索式确认领域边界、研究对象和证据密度。
## 适合什么问题

当你还不确定关键词怎么写、或者想先获得足够召回时，先用 PubMed。
## 指导架构

1. 第一层是把中文问题拆成“对象、机制、结局、研究类型”四块，避免一上来把限定词堆满。
2. 第二层是把概念翻译成 MeSH 词、同义词、缩写和近义表达，形成宽检索和窄检索两个版本。
3. 第三层是先看综述、再看近三年原始研究，然后回到最关键的实验设计和样本。
4. 第四层是把检索结果转成后续工具可用的材料，例如交给 Consensus 做方向判断，或交给 ResearchRabbit 做引用扩展。
## 推荐使用流程

1. 先用一句中文明确研究问题，尽量包含对象、机制和结局。
2. 把问题拆成 3 到 5 个核心概念，再生成英文关键词和同义词。
3. 分别做宽检索、平衡检索和严格检索，比较召回与精确度。
4. 把检索结果里最关键的综述和原始研究单独导出，作为下一步阅读材料。
## 中文使用示例

### 从中文问题生成检索式

```text
请把这个问题改写成适合 PubMed 的检索思路和布尔检索式：IL-17 是否影响肿瘤微环境中的 CD8+ T 细胞耗竭？请同时给我宽检索、平衡检索和严格检索三个版本。
```

### 围绕新主题做关键词扩展

```text
我想研究“肠道菌群与免疫治疗反应”，请给我核心英文关键词、常见同义词、可能的 MeSH 词，以及容易漏掉的相关变量。
```

### 从检索结果转阅读清单

```text
我已经搜到很多结果，请帮我判断哪些类型的论文应该先读：综述、临床研究、动物实验、机制研究。并告诉我每类该看什么。
```
## 常见误区

- 一开始就把所有限定词都塞进检索式，结果召回过低。
- 只盯着标题中的关键词，不检查摘要和 MeSH 语义。
- 把 PubMed 当成最终结论来源，而不是文献发现入口。
## 和相邻工具的区别

- 和 Consensus 搭配时，先用 PubMed 找到足够的原始文献，再用 Consensus 判断方向是否一致。
- 和 ResearchRabbit 搭配时，先确定种子论文，再用图谱扩大引用网络。
- 和 ChatGPT 搭配时，先让它帮你做关键词脑暴，再回到 PubMed 验证检索式。

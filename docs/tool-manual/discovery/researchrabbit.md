# ResearchRabbit 使用说明

> 分类：文献发现  |  按钮入口：生成图谱  |  适用日期：2026-05-06
> 目标：把这个工具页写成可直接交给网页改版 AI 的完整说明稿。

## 这个工具做什么

ResearchRabbit 适合追踪论文之间的引用和相似关系，帮助你从几篇种子论文扩展到一个领域的知识图谱。
## 适合什么问题

当你已经有核心论文，想看它们如何连成网络、谁是关键作者、后续研究往哪里走时，用 ResearchRabbit。
## 指导架构

1. 第一层是先选少量高质量种子论文，不要一开始就放太多杂乱材料。
2. 第二层是从相似论文、引用论文和被引用论文三个方向扩展。
3. 第三层是把高频节点和关键作者单独标记，形成你的领域地图。
4. 第四层是把图谱里最关键的论文回收到 PubMed 或 Wispaper 深读。
## 推荐使用流程

1. 先放入 3 到 5 篇与你研究问题最相关的种子论文。
2. 查看相似文献和上下游引用链，识别高频节点。
3. 逐轮加入最有价值的论文，扩大图谱范围。
4. 把最关键的分支整理成“先看谁、后看谁”的阅读顺序。
## 中文使用示例

### 从种子论文扩展

```text
我有 3 篇关于肝癌免疫微环境的种子论文，请帮我判断：哪些论文适合作为继续扩展的中心节点，哪些只是边缘参考。
```

### 寻找领域路径

```text
请帮我围绕“肿瘤相关巨噬细胞”梳理引用网络：关键作者、关键转折论文、以及近五年的新分支。
```
## 常见误区

- 把不相关的论文混进种子集合，导致图谱噪声很大。
- 只看热度最高的节点，不看早期奠基论文。
- 图谱看完就结束，不把关键论文回收到精读工具。
## 和相邻工具的区别

- 和 PubMed 搭配时，PubMed 负责找论文，ResearchRabbit 负责看关系。
- 和 Consensus 搭配时，先确定方向，再用图谱找到支撑或反对证据。
## 给网页改造 AI 的提示

- 网页说明要把“种子论文”这个概念讲清楚。
- 建议在图谱页补一个“从一个节点扩展到多个节点”的示意流程。

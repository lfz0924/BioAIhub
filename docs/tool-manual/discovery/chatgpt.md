# ChatGPT 使用说明

> 分类：文献发现  |  按钮入口：访问数据库  |  适用日期：2026-05-06
> 目标：把这个工具页写成可直接交给网页改版 AI 的完整说明稿。

## 这个工具做什么

ChatGPT 在文献发现阶段更像思考和改写助手，适合拆题、脑暴关键词、生成检索式和解释概念。
## 适合什么问题

当你还没把问题转成英文检索语言，或者想先做关键词脑暴时，用 ChatGPT。
## 指导架构

1. 第一层是先把研究问题拆成概念块，再考虑检索语言。
2. 第二层是让模型输出同义词、缩写、相关变量和排除词。
3. 第三层是把这些词整理成布尔检索式，并用人工规则检查覆盖范围。
4. 第四层是把生成结果回到 PubMed 或 Consensus 做验证，避免模型幻觉。
## 推荐使用流程

1. 先用中文描述你的研究主题和研究目标。
2. 让模型列出核心变量、同义词和容易遗漏的关键词。
3. 再让它生成宽、中、严三个检索版本。
4. 对生成结果做人工复核，补充你领域里更专业的词。
## 中文使用示例

### 关键词脑暴

```text
请围绕“肿瘤相关巨噬细胞”给我 20 个英文同义表达、常见缩写、相关机制词和容易遗漏的关键词。
```

### 生成检索式

```text
请把“PD-1 联合化疗用于晚期肺癌”改成适合 PubMed 的检索式，并解释每一组关键词为什么这样放。
```

### 解释概念

```text
请用中文解释“tumor microenvironment”在免疫研究里通常包含哪些子概念，以及检索时应该关注什么。
```
## 常见误区

- 把模型输出直接当成最终检索式，而不检查覆盖面。
- 只让模型给关键词，不让它说明每个词对应的概念边界。
- 把 ChatGPT 当成数据库，而不是检索前的结构化助手。
## 和相邻工具的区别

- 和 PubMed 搭配时，先用 ChatGPT 做概念拆解，再去 PubMed 验证。
- 和 Wispaper 搭配时，先由 ChatGPT 组织问题，再由 Wispaper 阅读论文。
## 给网页改造 AI 的提示

- 文档里要明确“它不负责最终检索，负责结构化思考”。
- 示例最好包含“生成检索式”和“解释概念”两种不同任务。

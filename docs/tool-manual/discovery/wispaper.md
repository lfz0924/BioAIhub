# Wispaper 使用说明

> 分类：文献发现  |  按钮入口：访问数据库  |  适用日期：2026-05-06
> 目标：把这个工具页写成可直接交给网页改版 AI 的完整说明稿。

## 这个工具做什么

Wispaper 更适合阅读复杂论文，尤其是需要把论文结构、方法和结果用中文讲清楚的时候。
## 适合什么问题

当你手里已经有一篇论文，想快速读懂它在说什么时，用 Wispaper。
## 指导架构

1. 第一层是先按论文结构阅读，而不是从头到尾线性扫一遍。
2. 第二层是先看背景、方法、结果，再追问统计、实验设计和局限。
3. 第三层是把单篇论文读懂后，再转入 Elicit 或 ResearchRabbit 做批量整理。
4. 第四层是把阅读结果沉淀为自己的中文笔记，方便后续写作。
## 推荐使用流程

1. 先打开目标论文或上传 PDF。
2. 要求工具按“背景-方法-结果-结论”分段解释。
3. 再追问你看不懂的公式、图表或统计方法。
4. 把阅读结果整理成你自己的中文笔记。
## 中文使用示例

### 结构化阅读

```text
请把这篇论文按背景、方法、结果、局限性拆开解释，并用中文总结每一部分最重要的信息。
```

### 方法追问

```text
请重点解释这篇论文的统计模型、纳排标准和主要变量，尽量用通俗中文说明。
```
## 常见误区

- 一上来就问结论，不先搞清论文结构。
- 把工具回答当成最终中文笔记，不再回原文核对。
- 需要做表格抽取时还继续在单篇阅读里耗时间。
## 和相邻工具的区别

- 和 Elicit 搭配时，Wispaper 负责“读懂”，Elicit 负责“抽取”。
- 和 Google AI Studio 搭配时，Wispaper 适合精读，Google AI Studio 适合多文献汇总。
## 给网页改造 AI 的提示

- 网页文案要保留“阅读助手”而不是“检索工具”的定位。
- 建议给“背景 / 方法 / 结果 / 局限性”做固定分区。
